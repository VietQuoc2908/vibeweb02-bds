# NhàĐất Việt (demo)

Trang chủ mẫu cho một kênh mua bán, cho thuê nhà đất – bài thực hành buổi 1. HTML/CSS/JS thuần, dữ liệu giả lập.

## Chạy thử

Mở `index.html` trong trình duyệt, hoặc:

```bash
python3 -m http.server 8000
# rồi mở http://localhost:8000
```

## Cấu trúc

```text
index.html             Trang chủ
assets/css/style.css   Giao diện
assets/js/main.js      Dữ liệu mẫu + tương tác
assets/images/logo.svg Logo / favicon
.claude/CLAUDE.md      Quy tắc & kiến trúc dự án
```
